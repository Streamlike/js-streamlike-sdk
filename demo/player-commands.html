Player commands

The player is driven from the page through its postMessage API. This page sends every command it accepts: the transport ones, which work everywhere, and the four families that pick a track or a panel — subtitles, audio, interactions and chapters — which are not deployed in production yet.

The four track families are not deployed in production yet. Sending one here is expected to do nothing: a player swallows a command it does not know. That is the point of this page — the channel line on the right tells a player that never answered from one that answers everything except these four, which is the difference between "my page is broken" and "the command is not deployed".
It opens on a media carrying subtitles and chapters, so the buttons are built from the tracks /ws/media really declares rather than from guesses.

["seek", 30.4] and ["speed", 1.3] take a number, ["volume", 0.5] a value between 0 and 1. The relative seeks count from the position the player last reported, shown on the right.

Subtitles not deployed — ["subtitles", …]

A language code turns that track on, null turns subtitles off. Mirrors subtitle=. The buttons carry subtitles[].subtitle.language_id as the webservice gives it: the suffix is part of the code, and fr-cc — closed captions in French — is a track of its own, not a variant of fr.

Audio not deployed — ["audio", …]

Selects an audio track by language. Mirrors audio_lng=, whose -ad suffix targets a language's audio description. The buttons come from metadata.audio_tracks[].audio_track, with its label and kind on the tooltip; a media carrying one track declares none, and global.is_multiple_audio is what says whether there is anything to choose from.

Interactions not deployed — ["interactions", …]

true turns interactions on in the browser language, a language code forces one, null turns them off. Mirrors interaction=. Nothing in /ws/media lists them, so the language buttons are the media's own language_ids, offered as candidates rather than discovered.

Chapters not deployed — ["chapters", …]

true shows the chapters, a language code forces one, false hides them. Mirrors chapter=. The buttons come from chapters[].chapter.language_id. Note the disabling value: false here, where subtitles and interactions take null.

Anything else

Sent as written, so a value can be probed exactly: ["subtitles", 0] is not ["subtitles", "0"], and neither is ["subtitles", null].
