Streamlike JS SDK - Playlist Player from CDN

Same demo as Playlist Player, but the SDK is loaded from a public CDN instead of the local dist/ folder: no npm install, no build step. The SDK has no runtime dependency, so dist/index.mjs is directly importable by the browser.

Back

The two integration modes

ES module — the recommended one, used by this very page:

<script type="module">
    import { generatePlaylistPlayer } from 'https://cdn.jsdelivr.net/npm/js-streamlike-sdk@3.8.0/dist/index.mjs';

    await generatePlaylistPlayer('my-player', { playlistId: 'c4da86fddd8f0ada' });
</script>

Classic script — for pages that cannot use ES modules; everything lands on the Streamlike global:

<script src="https://cdn.jsdelivr.net/npm/js-streamlike-sdk@3.8.0/dist/index.global.js"></script>
<script>
    Streamlike.generatePlaylistPlayer('my-player', { playlistId: 'c4da86fddd8f0ada' });
</script>
